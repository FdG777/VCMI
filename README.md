# VCMI
Reactive MVC architecture with an intermediate round-trip serialization layer


VCMI is a reactive Model–View–Controller architecture with a strong focus on
explicit and highly typed models, controllers, and views.

A central aspect of the framework is an intermediate round-trip serialization
layer that allows lossless serialization and reconstruction of framework
components.

The codebase emphasizes structural clarity, strict typing, and explicit
architectural patterns over convenience abstractions.

This repository currently serves as a reference implementation and an evolving
experimental code base.
